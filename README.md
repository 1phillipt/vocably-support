# Vocably – App Support

Vocably is a vocabulary learning app designed to help users improve their English through interactive matching games, definitions, synonyms, and antonyms.

---

## Features
- Definition Match
- Synonym Match
- Antonym Match
- Progress-based learning sessions
- Clean, distraction-free interface
- Offline-friendly vocabulary practice

## Privacy

Vocably does **not** collect personal data.

- No account required
- No user tracking
- No third-party analytics
- No data sold or shared

All learning progress is stored locally on your device.
